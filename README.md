# Personal Portfolio – Shihana Fathima S

A responsive personal portfolio website showcasing my profile, education, technical skills, projects, research, achievements, and certifications.

## Tech Stack
- HTML5
- CSS3
- JavaScript

## Features
- About Me and Education
- Technical Skills
- Featured Projects
- Research and Publications
- Certifications and Achievements
- Contact and Social Links
- Responsive Design

## Run Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/shihanafathima-s/FUTURE_FS_01.git
   ```
2. Open the project folder.
3. Run `index.html` in your browser or use VS Code Live Server.
